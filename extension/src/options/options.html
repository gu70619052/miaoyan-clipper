妙言剪藏

把网页正文、选段、框选区域和截图，变成妙言 Markdown 笔记。

妙言笔记库

妙言没有对外接口，本扩展用 Chrome 的文件系统权限直接写库目录里的 Markdown 文件。 授权一次长期有效，笔记始终留在你自己的磁盘上。

未授权

默认位置：iCloud Drive › 妙言 › Documents；也可以选任意目录，扩展会在其中建分类。

浏览器重启、扩展重载或 iCloud 目录重新挂载后，目录授权会被退回「待确认」状态： 这时点「重新授权此目录」确认一次即可，不用重新找目录。

保存行为

这里的默认目录只在「还没用过」时生效；剪藏面板会优先带出你最近一次保存用的目录，仍然可以临时改。

网站访问权限

从 v0.6.0 起，本扩展不再常驻访问所有网站： 你点扩展图标、右键菜单或按快捷键时，Chrome 只把当前这一个站点临时交给我们； 别的网站我们一概看不到。

只有一种情况会长期保留某个站点的访问权：正文里的图片在别的网站（CDN 之类）上， 想把它们也下载到本地时，会按站点单独问你一次。不授权也没关系，图片会保留原始链接。

    用法速查
    
        
      
          
    • 点扩展图标：直接剪藏当前页（自动识别正文），页面上会摆出范围框，可以拖动手柄调整范围，确认后弹出卡片直接保存。
      • 
          
    • 快捷键：⌘/Ctrl + Shift + S 剪藏整篇、+ Shift + K 框选、+ Shift + P 截图剪藏（可在 Chrome 扩展快捷键页面改成你顺手的键）。
      • 
          
    • 框选剪藏：页面空白处右键 →「妙言剪藏：框选剪藏」→ 拖拽选区 → 自动定位对应正文块。
      • 
          
    • 选中文字：划选文字后右键 →「妙言剪藏：剪藏选中文字」。
      • 
          
    • 整篇正文：右键 →「妙言剪藏：整篇正文」，自动识别文章主体。
      • 
          
    • 截图剪藏：右键 →「妙言剪藏：截图剪藏」→ 在截图上再拖一次裁剪（需要先点一次扩展图标授权）。
      • 
          
    • 侧边栏：点扩展图标不会打开侧边栏了；用 Chrome 工具栏右侧的「侧边栏」按钮打开，可以编辑 Markdown 后再保存。
