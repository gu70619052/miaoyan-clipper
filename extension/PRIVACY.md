# 妙言剪藏 · 隐私政策

最后更新：2026-11-23 · 适用于「妙言剪藏」Chrome 扩展（版本 0.5.0）

> 网页版（可直接托管）：`store/privacy.html`

## 一句话结论

**本扩展不收集、不上传、不共享任何用户数据。**
所有剪藏内容只写进你自己电脑上、由你自己授权的妙言笔记库目录（普通本地文件夹或 iCloud Drive 等你自己的同步盘）。
扩展没有服务器、没有账号、没有统计代码。

## 一、扩展会碰哪些东西

- **网页正文**：只有你在网页上主动触发剪藏（点击浮层、右键菜单或扩展图标）时，才会读取当前页面的可见内容，转成 Markdown。
- **网页图片**：剪藏正文里的图片时，扩展会把图片下载到你指定目录下的 `i/` 附件目录里，正文里写成 `/i/文件名` 引用；图片原地址来自你正在看的那个网页。
- **截图**：只有你主动用「截图剪藏」时才会截取当前标签页的可视区域，截图同样只写入你的笔记目录。
- **你的妙言库目录**：第一次使用时，你会手动选择一个目录（通常是 `~/Library/Mobile Documents/iCloud~com~tw93~miaoyan/Documents`）。扩展只对这个目录有读写权限。
- **少量本地设置**：默认目标目录、是否下载图片、是否写 frontmatter 等开关，存在浏览器的 `chrome.storage.local` 里；剪藏草稿临时存在 `chrome.storage.session`（关闭浏览器即失效）。

## 二、唯一的对外网络请求

扩展只会在你剪藏一篇含图片的网页时，去请求**那个网页里引用的图片地址**，把图片存到本地。
请求不携带任何 Cookie（`credentials: 'omit'`），也不带身份信息。

出于安全考虑，扩展**默认拒绝下载内网地址**（`localhost`、`127.0.0.1`、`192.168.*`、`10.*`、`169.254.*` 等）的图片，避免被网页用来探测你局域网里的服务。如果你确实需要，可在扩展设置页手动打开开关。

除图片下载外，扩展**不发起任何网络请求**：没有统计、没有广告、没有远程配置、没有远程代码。

## 三、权限说明

| 权限 | 用来做什么 | 为什么必须 |
| --- | --- | --- |
| `storage` | 保存设置与草稿 | 纯本地存储，不外传 |
| `contextMenus` | 右键菜单里的「妙言剪藏：整篇/选中文字/框选/截图」 | 这是剪藏的入口 |
| `sidePanel` | 在侧边栏里编辑与保存剪藏内容 | 让你能在保存前改标题、选目录 |
| `activeTab` | 对当前标签页执行剪藏与截图 | 截图剪藏需要用户授权后才能截取当前页 |
| `http://*/*`、`https://*/*` | 在网页上注入剪藏浮层、下载正文里的图片 | 只在你主动剪藏时才会用到 |

## 四、网页能不能偷看你的妙言库？

不能。扩展的浮层使用 **closed shadow DOM**，宿主元素 id 每次注入随机生成，网页脚本读不到浮层内容，也就读不到你的目录结构；扩展还拒绝执行来自网页的指令，不会替网页往你的笔记库里写东西。

## 五、数据保存在哪里、怎么删

剪藏结果以 Markdown 文件形式保存在**你授权的目录**里（笔记 `.md` 文件 + `i/` 附件目录）。
想全部删除，直接在妙言 App 或文件管理器里删除这些文件即可。扩展本身不保存任何副本；撤销授权（设置页「清除授权」）会同时清掉扩展里缓存的目录列表。

## 六、变更与联系

本政策随扩展版本更新，重大变更会在扩展更新说明里注明。有问题可以在扩展的 GitHub 仓库提 issue。
