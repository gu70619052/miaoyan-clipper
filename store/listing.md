## 2. 详细说明（商店介绍，长版）

```
【第三方非官方插件】妙言剪藏由个人开发者独立开发，与妙言（MiaoYan）App 及其作者 tw93 无隶属、授权或合作关系。
「妙言」只是用来说明它能把内容存进哪个应用；妙言的商标与著作权归其所有者所有。

把「看到一篇好文章 → 存进自己的笔记库」这件事做得干净一点。

妙言剪藏是一个本地优先的网页剪藏工具：内容不会经过任何服务器，
直接以 Markdown 文件写进你自己授权的妙言笔记库目录，
用妙言 App 打开就能接着编辑、搜索、加标签。

四种剪藏方式：
· 整篇正文 —— 自动识别页面里最重要的那块正文（段落打分，不是「字最多那块」）
· 选中文字 —— 先选中再剪
· 框选区域 —— 拖一个框，只剪框里的内容
· 截图剪藏 —— 截当前可视区域，存成图片笔记

权限上尽量克制：安装时不申请任何网站访问权，
只有你点下去剪藏时 Chrome 才把当前这一个页面临时交给它；
只有要把正文里的跨站图片存到本地时，才会按站点单独问你一次。

发起剪藏有三个入口，随手用哪个都行：
· 点地址栏旁的扩展图标 —— 直接剪当前页（像印象笔记那样）
· 快捷键 —— ⌘/Ctrl + Shift + S 整篇、+ K 框选、+ P 截图
· 页面右键菜单 —— 整篇正文 / 选中文字 / 框选区域 / 截图剪藏

剪藏时会在页面上摆一个范围框：
默认已经框在识别到的正文上，可以拖 8 个手柄改大小、拖标签整体挪位置，
确认了才剪。广告位、推荐栏、热榜这类噪声会被自动剔除。

保存时：
· 侧边栏里可以改标题、写标签、选目标分类
· 会自动带出你最近一次保存用的目录
· 标签也会记住，下次剪藏自动填好
· 保存成功浮层自动收起，底部留一条提示，可以直接「继续剪藏」下一篇
· 剪藏过的页面标签上会打一个 ✓
· 图片下载到该分类下的 i/ 目录，正文里用 /i/文件名 引用，离线可看
· frontmatter 写好 title、来源、站点、作者、剪藏时间、标签，妙言里能当元数据用

隐私：
· 没有账号、没有服务器、没有统计、没有任何第三方请求
· 唯一的对外请求是下载你正在看的那篇网页里的图片，且不带 Cookie
· 默认拒绝下载内网地址的图片，避免被网页拿来探测你的局域网
· 浮层用 closed shadow DOM，网页脚本读不到你的目录结构

需要 Chrome 116 或更高版本；首次使用需要你手动授权一次妙言笔记库目录。

致谢与许可：
· 扩展图标取自妙言 App（tw93/MiaoYan，MIT License, Copyright (c) 2022 Tw93），仅用于表明兼容关系；
· 本扩展未使用妙言的源代码，只按其公开的 Markdown 文件格式与 i/ 附件目录约定写入文件；
· 源码与本隐私政策公开在 github.com/gu70619052/miaoyan-clipper
```

## 3. 权限理由（逐条，可直接粘贴）

| 权限 / 主机权限 | 商店里填的理由 |
| --- | --- |
| `storage` | 仅在本机保存扩展设置（默认目录、是否下载图片等）与临时剪藏草稿，不上传、不共享。 |
| `contextMenus` | 为剪藏提供右键菜单入口：整篇正文 / 选中文字 / 框选区域 / 截图剪藏。 |
| `sidePanel` | 在浏览器侧边栏里展示剪藏结果，让你在保存前修改标题、填写标签、选择目标目录。 |
| `activeTab` | 用户主动触发剪藏（点图标 / 右键菜单 / 快捷键）后，扩展才临时获得当前标签页的访问权；没有手势就不碰任何页面。截图剪藏也依赖这次授权。 |
| `scripting` | 剪藏脚本按需注入：只有用户触发剪藏的那一刻，才把剪藏脚本注入当前标签页（v0.6.0 起不再静态注入到所有网页）。 |
| `tabs` | 读取当前标签页的标题与网址，用于判断能否剪藏、写来源链接、判断侧栏草稿是否属于当前页。不读取页面内容。 |
| 可选主机权限 `http://*/*`、`https://*/*`（`optional_host_permissions`） | **安装时不申请**。只在你要把正文里的跨站图片下载到本地时，按站点弹一次授权；拒绝也能保存，图片保留原始链接。 |

> **v0.6.0 的关键变化**：`manifest.json` 里已经没有 `host_permissions`，也没有 `content_scripts`
> —— 安装时不申请任何主机权限，也不再提前注入到所有网页。剪藏靠 `activeTab`（用户手势）
> + `chrome.scripting.executeScript` 按需注入；跨站图片下载才用可选主机权限。
>
> 审核备注（如果审核员问）：扩展不注入任何远程脚本，全部代码打包在扩展内；
> `marked.min.js` 为本地打包的开源 Markdown 渲染器（MIT 许可证，随包附带 `marked.LICENSE.md`）。
>
> 快捷键说明：扩展注册了 3 个 `commands`（⌘/Ctrl + Shift + S / K / P），
> Chrome 允许每个扩展最多 4 个建议快捷键；这 3 组键位在 macOS 上不与浏览器保留键冲突。

> 为什么不能选「不收集」：Chrome 官方《User Data FAQ》第 3 问要求「即使只在本机处理、也未传给第三方，也必须披露」，

> 三类数据都只写进你自己的妙言库文件，**不上传、不共享、不出售**。

- 唯一需要说明的对外请求：从用户正在浏览的网页下载图片（`credentials: 'omit'`，不携带任何账号信息）；
  默认拒绝内网地址，可在设置页手动打开。

## 5. 单一用途说明（供审核填「Single purpose description」）

```
妙言剪藏的唯一用途是：把用户正在浏览的网页内容，以 Markdown 笔记的形式保存到用户本地的妙言笔记库目录。
所有功能（正文识别、选段、框选、截图、目标目录、图片离线化、frontmatter）都服务于这一件事，
没有与该用途无关的功能（无联网检索、无账号体系、无统计、无广告、无云同步）。
```

## 7. 版本说明（每个版本都要写）

### 0.6.0

```
权限最小化：安装时不再申请任何网站访问权限。
· 剪藏改为「点图标 / 右键 / 快捷键」时由 Chrome 临时授权当前标签页（activeTab），
  随后按需注入剪藏脚本；不再提前、也不静态注入到所有网页
· 只有把正文里的跨站图片下载到本地时，才会按站点弹一次授权；
  拒绝也能正常保存，图片保留原始链接
· 设置页新增「网站访问权限」：可查看保留的站点、一键全部撤销
· 保存结果会明确提示「N 张图片未下载到本地，已保留原始链接」
```

### 0.5.0
```
交互优化（参照印象笔记、Obsidian Web Clipper、Notion Web Clipper 的做法）：
· 点地址栏旁的扩展图标即可剪藏当前页，不再只能从网页右键发起
· 新增快捷键：⌘/Ctrl + Shift + S 整篇、+ K 框选、+ P 截图
· 保存成功后浮层自动收起，底部提示条可直接「继续剪藏」下一篇
· 记住上次用的标签，下次剪藏自动填好
· 剪藏过的页面在标签上打 ✓ 角标
· 侧边栏空状态与「上一篇文章」提示条都提供「剪藏当前页面」按钮
· 切换标签页或在当前页换网址时，侧边栏能正确判断草稿是不是当前页的
```

### 0.4.0
```
修复与加固：
· 保存时不再反复要求目录授权：改成「先写后申请」，只在真的写不动时才确认一次
· 记住最近一次保存用的目录，下次自动带出
· 修复并发保存同名笔记会互相覆盖的问题
· 修复同名笔记在大小写不敏感的磁盘上被覆盖的问题
· 修复图片占位符在 11 张以上时错位丢图的问题
· 附件名不再包含空格与括号，正文里的 /i/ 链接不会断
· 浮层改为 closed shadow DOM + 随机宿主 id，网页读不到你的目录结构
· 图片下载增加超时、体积上限，默认拒绝内网地址
· 截图剪藏改为压缩后的 JPEG，避免会话存储超限
· 识别与转换：隐藏元素（计算样式 / 未展开 details）不再被剪进笔记；正文里的 < > & 会正确转义
· 删除未使用的 scripting 权限与测试用入口
```
