妙言剪藏 · 隐私政策

最后更新：2026-11-23 · 适用于「妙言剪藏」Chrome 扩展（版本 0.5.0）

一句话结论

本扩展只在你自己的电脑上处理三类数据：网站内容、浏览活动（你剪藏的那个页面网址与时间）、你在侧边栏里输入的标题和标签。 这些数据只写进你自己授权的妙言笔记库目录（普通本地文件夹或 iCloud Drive 等你自己的同步盘）， 不上传、不共享、不出售，也不用于剪藏以外的任何用途。 扩展没有服务器、没有账号、没有统计代码。

一、数据使用披露（与 Chrome 应用商店后台的声明一致）

Chrome 应用商店披露项本扩展的情况
网站内容（文字、图片、链接） 会处理：剪藏时读取你当前页面的可见文字与图片，截图剪藏时截取当前标签页的可视区域。 在本机转成 Markdown 写入你的笔记目录，不上传。
网络记录 / 浏览活动（页面网址、访问时间） 会处理：记录你正在剪藏的页面网址与剪藏时间（写进笔记的 frontmatter）； 浏览器会话里保留「最近活动标签页的网址」，仅用于在侧边栏提示「这篇草稿不是当前页」。 不保留浏览历史列表，不上传。
用户活动（你在扩展里的输入与操作） 会处理：保存你在侧边栏输入的标题与标签（写进笔记），以及剪藏过的标签页上的 ✓ 角标（只存在于当前浏览器会话）。
个人身份信息 / 健康信息 / 财务和付款信息 / 身份验证信息 / 个人通讯 / 位置 不涉及。扩展不读取密码框、隐藏元素、Cookie、表单值，也不做身份识别或位置推断。 网页内容里若含作者名等信息，属于上面的「网站内容」，只做原样搬运。

按 Chrome 应用商店的用户数据政策，以上三类属于「只在本机处理」：数据不出你的设备， 因此既没有加密传输环节，也没有任何第三方接收方。扩展遵守商店的有限使用要求 —— 不出售用户数据、不向第三方传输用户数据、不用于单一用途（网页剪藏）以外的目的， 也不允许开发者或雇员查看用户的剪藏内容。

二、扩展会碰哪些东西

  • 网页正文：只有你在网页上主动触发剪藏（点击浮层、右键菜单或扩展图标）时，才会读取当前页面的可见内容，转成 Markdown。
  • 网页图片：剪藏正文里的图片时，扩展会把图片下载到你指定目录下的 i/ 附件目录里， 正文里写成 /i/文件名 引用；图片原地址来自你正在看的那个网页。
  • 截图：只有你主动用「截图剪藏」时才会截取当前标签页的可视区域，截图同样只写入你的笔记目录。
  • 你输入的标题与标签：侧边栏里填的标题和标签会写进笔记的 frontmatter，用于你日后检索。
  • 你的妙言库目录：第一次使用时，你会手动选择一个目录（通常是 ~/Library/Mobile Documents/iCloud~com~tw93~miaoyan/Documents）。扩展只对这个目录有读写权限。
  • 少量本地设置：默认目标目录、是否下载图片、是否写 frontmatter 等开关，存在浏览器的 chrome.storage.local 里；剪藏草稿临时存在 chrome.storage.session（关闭浏览器即失效）。

三、唯一的对外网络请求

扩展只会在你剪藏一篇含图片的网页时，去请求那个网页里引用的图片地址，把图片存到本地。 请求不携带任何 Cookie（credentials: 'omit'），也不带身份信息。

出于安全考虑，扩展默认拒绝下载内网地址（localhost、127.0.0.1、 192.168.*、10.*、169.254.* 等）的图片，避免被网页用来探测你局域网里的服务。 如果你确实需要，可在扩展设置页手动打开开关。

除图片下载外，扩展不发起任何网络请求：没有统计、没有广告、没有远程配置、没有远程代码。

四、权限说明

权限用来做什么为什么必须
storage保存设置与草稿纯本地存储，不外传
contextMenus右键菜单里的「妙言剪藏：整篇/选中文字/框选/截图」这是剪藏的入口
sidePanel在侧边栏里编辑与保存剪藏内容让你能在保存前改标题、选目录
activeTab对当前标签页执行剪藏与截图截图剪藏需要用户授权后才能截取当前页
http://*/*、https://*/*在网页上注入剪藏浮层、下载正文里的图片只在你主动剪藏时才会用到

五、网页能不能偷看你的妙言库？

不能。扩展的浮层使用 closed shadow DOM，宿主元素 id 每次注入随机生成， 网页脚本读不到浮层内容，也就读不到你的目录结构；扩展还拒绝执行来自网页的指令， 不会替网页往你的笔记库里写东西。

六、数据保存在哪里、怎么删

剪藏结果以 Markdown 文件形式保存在你授权的目录里（笔记 .md 文件 + i/ 附件目录）。 想全部删除，直接在妙言 App 或文件管理器里删除这些文件即可。扩展本身不保存任何副本； 撤销授权（设置页「清除授权」）会同时清掉扩展里缓存的目录列表；关闭浏览器即清空会话里的草稿与标签页角标。

七、变更与联系

本政策随扩展版本更新，重大变更会在扩展更新说明里注明。有问题可以在扩展的 GitHub 仓库提 issue。
